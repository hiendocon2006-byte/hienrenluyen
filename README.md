# Điểm Rèn Luyện Optimizer — GitHub Pages

## Deploy miễn phí
1. Tạo repository mới trên GitHub, ví dụ `diem-ren-luyen`.
2. Nếu dùng GitHub Free, chọn repository **Public** để dùng GitHub Pages.
3. Tải `index.html` trong thư mục này lên thư mục gốc của repository.
4. Mở **Settings → Pages**.
5. Trong **Build and deployment**, chọn **Deploy from a branch**, chọn branch `main` và folder `/(root)`, rồi bấm **Save**.
6. Đợi GitHub Pages publish; đường link thường có dạng `https://TEN_TAI_KHOAN.github.io/diem-ren-luyen/`.

## Lịch sử phiên bản code
Mỗi lần sửa `index.html` trên GitHub, hãy lưu bằng **Commit changes**. Mở file `index.html` rồi chọn **History** để xem các lần sửa trước đó.

## Lưu dữ liệu hoạt động
Trang hiện lưu danh sách bằng `localStorage` trong trình duyệt đang dùng. Dữ liệu không tự đồng bộ giữa các thiết bị/trình duyệt. Trang có nút **Lưu JSON** và **Tải JSON** để sao lưu/khôi phục danh sách.
