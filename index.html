Web đã có phần đăng nhập, nhưng chưa được kết nối với dự án Firebase của m.

Cần thiết lập một lần:

1. Tạo dự án Firebase và thêm ứng dụng Web.

2. Bật Authentication bằng Email/Password và tạo Cloud Firestore.

3. Trong file index.html, tìm const firebaseConfig và thay các giá trị PASTE_... bằng cấu hình Firebase của m.

4. Cài quy tắc Firestore theo file firestore.rules.txt đi kèm bộ tải xuống.

Không đặt mật khẩu, khóa tài khoản dịch vụ (service account) hoặc thông tin bí mật nào vào file HTML.

Đang kết nối hệ thống tài khoản...
